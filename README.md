# 17 - 高木-ワイエルシュトラスフラクタル曲線

**ビルド日**: 2026-11-03
**カテゴリ**: visual
**slug**: takagi-weierstrass-curve

## 概要
連続だがどこでも微分不可能なフラクタル次元の「病的曲線」をCanvas上に描画するツール。ワイエルシュトラス関数と高木関数に対応し、倍音数・振幅パラメータをリアルタイム調整できる。

## 機能
- ワイエルシュトラス関数（f(x) = Σ a^n·cos(b^n·π·x)）と高木関数の両対応
- 係数a（0.3〜0.9）・係数b（2〜15）・倍音数（1〜15）のスライダー
- 倍音数を1から順に増やすアニメーション機能
- フラクタル次元推定値をリアルタイム表示
- マウスホイール・ボタンによるズームコントロール
- グラジェントカラー描画
